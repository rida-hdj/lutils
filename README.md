# lutils

Because `gnu coreutils` was too good, i made worse one.

A collection of CLI tools that do some stuff.

## Commands

- `lutils pwd` - Tells you where you are
- `lutils mkdir <dir>` - Makes a directory
- `lutils touch <file>` - Creates a file. Because touching grass is overrated.

> Maybe I'll add more tools later

## Install

```bash
cargo install --path .
```

Or just compile the binary yourself with `cargo`

## Why?

Because sometimes you need Rust-written tools to feel superior.

And because I'm trying to learn Rust.
